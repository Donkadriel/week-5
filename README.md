# Week 5 — JavaScript Exercises

A collection of beginner JavaScript exercises, each paired with a simple HTML page that loads its script.

## Files

| File | Description |
| --- | --- |
| `fizzBuzz.html` / `fizzBuzz.js` | Prints numbers 1–100, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz". |
| `studentGrading.html` / `studentGrading.js` | Calculates a student's average score across four subjects and prints the results and a remark. |

## Usage

Open either `.html` file in a browser, then open the browser's developer console (F12 → Console) to view the output.

- `fizzBuzz.html` — FizzBuzz output
- `studentGrading.html` — Student grading report

## Grading Scale

| Average Score | Remark |
| --- | --- |
| 70 and above | Excellent |
| 50–69 | Good |
| 35–49 | You can do better |
| Below 35 | Fail |

## Requirements

A modern web browser. No build tools or dependencies required.
